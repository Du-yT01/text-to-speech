Xong! Có link https:// ngay lập tức

Vercel — Tốc độ nhanh nhất

2

cd chinese-tts/

✓
Link: project.vercel.app
CDN toàn cầu, HTTPS tự động.
Tại sao cần deploy?
❌ Mở file:// trực tiếp
Trình duyệt chặn CORS — không thể gọi HuggingFace API từ địa chỉ file://.
Piper offline vẫn hoạt động, nhưng các giọng MMS bị lỗi "Failed to fetch".
✓ Chạy trên https://
HuggingFace API cho phép gọi từ bất kỳ domain https:// nào.
Tất cả 7 giọng hoạt động — Piper offline + 5 giọng MMS online.
⚡ Chỉ cần 1 lần deploy
Sau khi có link https://, chia sẻ cho bất kỳ ai — họ mở link là dùng được ngay, không cần cài gì.
