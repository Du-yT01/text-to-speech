Hướng dẫn bên dưới sẽ được tô sáng phù hợp với máy bạn
Windows — Cài giọng tiếng Trung
1
Mở Settings
Nhấn Win + I để mở Windows Settings
2
Vào Time & Language → Speech
Trong menu trái chọn Time & language, sau đó nhấn Speech
3
Thêm giọng nói
Cuộn xuống phần "Manage voices", nhấn "Add voices"
4
Tìm và cài Chinese
Gõ Chinese vào ô tìm kiếm → chọn các giọng muốn cài → nhấn Add
Microsoft Xiaoxiao (Nữ · Phổ thông) Microsoft Yunyang (Nam · Phổ thông) Microsoft HiuMaan (Nữ · Quảng Đông) Microsoft HiuGaai (Nữ · Quảng Đông)
5
Khởi động lại trình duyệt
Đóng hoàn toàn Chrome/Edge rồi mở lại — giọng mới sẽ xuất hiện trong danh sách
macOS — Cài giọng tiếng Trung
1
Mở System Settings
Nhấn menu Apple () → System Settings
2
Vào Accessibility → Spoken Content
Tìm Accessibility trong danh sách bên trái → chọn Spoken Content
3
Nhấn System Voice → Customize
Click vào dropdown System Voice → chọn Customize... ở cuối danh sách
4
Tìm Chinese và tải về
Tìm Chinese → tích vào các giọng muốn cài → nhấn OK để tải về
Tingting (Nữ · Phổ thông) Sinji (Nữ · Quảng Đông) Meijia (Nữ · Đài Loan) Lekiu (Nam · Phổ thông)
5
Khởi động lại Safari / Chrome
Đóng và mở lại trình duyệt. Safari nhận giọng ngay; Chrome cần vài giây để reload.
Linux / Android / ChromeOS
1
Dùng Chrome trên Android
Android có sẵn Google Text-to-Speech hỗ trợ tiếng Trung. Mở ứng dụng trực tiếp trên Chrome di động.
2
Linux — Cài espeak-ng hoặc festival
Cài engine TTS hỗ trợ tiếng Trung:
sudo apt install espeak-ng
sudo apt install speech-dispatcher
3
Hoặc dùng Chrome + Google TTS
Chrome trên Linux đôi khi tích hợp giọng Google — thử reload trang này trong Chrome và kiểm tra danh sách bên phải.
